# PLANAZO!

¿Qué pinta hoy?

PLANAZO! es una plataforma pensada para ayudar a las personas a descubrir experiencias y actividades para hacer en Buenos Aires.

La idea nació de una pregunta simple: ¿Qué podemos hacer hoy?

En el sitio se podrán encontrar diferentes tipos de planes, como gastronomía, cultura, paseos y entretenimiento, reunidos de una manera simple y visual.

El objetivo del proyecto es transformar la búsqueda de algo para hacer en una experiencia rápida, divertida y práctica.

Este proyecto será desarrollado como parte del curso de Front-End JavaScript de Talento Tech, aplicando de manera progresiva los conocimientos aprendidos durante las clases.

Para su desarrollo se utilizarán HTML, CSS y JavaScript.

Buenos Aires, Argentina
